# Personal Finance Tracker

A cross-platform Flutter app for tracking income, expenses, and budgets with a modern, responsive UI. Built with Firebase for authentication and Firestore for data storage, it features spending visualization, budget alerts, and a clean user experience optimized for mobile and web.

## Features
- **Authentication**: Login, signup, email verification, forgot/reset password.
- **Transaction Management**: Add, edit, delete income/expense entries.
- **Budget Tracking**: Set monthly budgets with alerts.
- **Spending Visualization**: Pie chart for expense breakdown.
- **Responsive UI**: Works on iOS, Android, and web with animations.
- **Dark/Light Mode**: Theme switching for accessibility.

## Technologies Used
- Flutter/Dart
- Firebase (Authentication, Firestore)
- BLoC for state management
- fl_chart for visualizations
- flutter_animate for UI animations
